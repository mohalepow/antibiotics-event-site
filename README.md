# دليل موقع فعالية التوعية بالمضادات الحيوية

موقع عربي تفاعلي لعرض البوثات، واللعبة، والاختبار، والإنجازات، ولوحة المتصدرين، ولوحة الإدارة.

## محتويات المشروع

- `index.html`: واجهة الموقع.
- `style.css`: التنسيق والتوافق مع الهاتف والكمبيوتر.
- `app.js`: وظائف الموقع واللعبة وإدارة البوثات.
- `config.js`: رابط Supabase ومفتاح Publishable.
- `assets/`: الصور والخطوط والشعار.
- `supabase-upgrade-score-once.sql`: ترقية منع تكرار نتيجة الجولة.

## إعداد Supabase

1. أنشئ مشروعًا في Supabase.
2. انسخ Project URL ومفتاح Publishable من إعدادات API.
3. افتح `config.js` وضع القيم في `SUPABASE_URL` و`SUPABASE_ANON_KEY`.
4. لا تضع `service_role` أو Secret key في ملفات الواجهة العامة.
5. تأكد من تطبيق ملفات SQL الأساسية الخاصة بإنشاء جداول الموقع والإنجازات ولوحة الإدارة.

## منع تكرار نتيجة اللعبة

بعد تطبيق ترقية الجداول والإنجازات السابقة، نفّذ ملف `supabase-upgrade-score-once.sql` مرة واحدة من Supabase SQL Editor.

تعطي اللعبة كل جولة معرّفًا فريدًا، وتتحقق قاعدة البيانات من عدم تسجيل المعرّف نفسه سابقًا. بعد نجاح الحفظ يتعطل زر التسجيل لهذه الجولة. بدء جولة جديدة ينشئ معرّفًا جديدًا ويسمح بتسجيل نتيجتها بصورة مستقلة.

**مهم:** هذه الحماية تمنع تكرار إرسال نتيجة الجولة نفسها. وليست نظامًا متقدمًا لمنع الغش أو للتحقق المستقل من نتيجة يرسلها المتصفح؛ ذلك يتطلب نقل منطق التحقق إلى خادم موثوق.

## إدارة البوثات ومعاينة الموقع

1. سجّل الدخول بحساب مدير مضاف في جدول `admin_users`.
2. افتح إدارة البوثات ثم أضف بوثًا أو عدّل بوثًا موجودًا.
3. تظهر معاينة مباشرة لصورة المخطط داخل محرر البوث.
4. اسحب العلامة بإصبعك على الهاتف أو بالفأرة على الكمبيوتر. تتحدث قيم X وY تلقائيًا.
5. احفظ البوث لاعتماد موضعه للزوار.

يمكن تغيير صورة المخطط من قسم «صورة مخطط الفعالية» في لوحة الإدارة.

## شعار الموقع والخطوط

- الشعار: `assets/images/site-logo.png`.
- خطوط Amiri وNoto Sans Arabic موجودة في `assets/fonts/`.
- إذا غيّرت مسار الشعار، حدّث `src` في `index.html`.

## النشر على GitHub Pages باستخدام Deploy from a branch

1. ارفع محتويات مجلد `antibiotics-event-site` إلى مجلد النشر الذي اخترته في المستودع.
2. افتح Settings ثم Pages.
3. اختر Deploy from a branch.
4. اختر الفرع `main` ومجلد النشر الصحيح (`/ (root)` أو `/docs` حسب ترتيب المستودع).
5. احفظ وانتظر اكتمال نشر GitHub Pages.
6. حدّث الموقع تحديثًا كاملًا بعد النشر.

## اختبار التحديث

- جرّب بدء جولة لعبة وإنهاءها ثم تسجيل النتيجة.
- اضغط زر تسجيل النتيجة مرة ثانية: يجب أن يبقى معطلًا وتظهر رسالة أن الجولة سُجلت.
- جرّب جولة جديدة: يجب أن تحصل على معرّف جديد ويمكن تسجيلها.
- افتح محرر البوث واسحب العلامة داخل المعاينة، ثم احفظ وتأكد من ظهور الموقع الجديد على الخريطة العامة.

## ملاحظات أمنية

مفتاح Publishable مخصص للمتصفح، لكن يجب تفعيل RLS وكتابة سياسات مناسبة على جداول Supabase. لا تمنح الزوار صلاحيات مباشرة لتعديل بيانات الإدارة أو منح الأوسمة أو تغيير النقاط. احتفظ بمفاتيح Secret وService Role في بيئة خادم آمنة فقط.

## شاشة الترحيب الافتتاحية
- تظهر شاشة افتتاحية متحركة عند فتح الموقع.
- تعرض رسالة الترحيب بفعالية نادي يقن في كلية الصيدلة بجامعة أم القرى، ثم تعرض MADE BY Dr.GHOST | X : @dr0ghost لفترة قصيرة، وبعدها تفتح الصفحة الرئيسية تلقائيًا.
- يوجد زر «تخطي المقدمة» لتجاوز الحركة مباشرة.
- تحترم الشاشة إعداد تقليل الحركة في الجهاز (prefers-reduced-motion).

## رموز QR وزيارات البوثات والإنجازات الديناميكية

1. نفّذ `supabase-upgrade-booth-visits.sql` مرة واحدة في Supabase SQL Editor بعد إنشاء جدول `booths`.
2. افتح لوحة الإدارة ثم إدارة البوثات. سيظهر زر `QR` بجانب كل بوث.
3. افتح رمز QR الخاص بالبوث واطبعه أو اعرضه عند الركن.
4. عند مسح الزائر للرمز بكاميرا الهاتف، يفتح رابط الموقع معرّف البوث. يكتب الزائر الاسم نفسه المستخدم في ملف الإنجازات ثم يضغط «تأكيد زيارتي».
5. تظهر شارة مستقلة باسم البوث في «إنجازاتي وشاراتي». أسماء الشارات تُقرأ مباشرة من أسماء البوثات الحالية في لوحة الإدارة؛ إضافة بوث جديد تنشئ شارة مقفلة تلقائيًا، وزيارته تفتحها.
6. تُسجل الزيارة مرة واحدة لكل اسم مشارك ولكل بوث. إعادة مسح الرمز تعرض أن الزيارة مسجلة سابقًا.

**مهم بخصوص الهوية:** ربط الزيارات هنا يعتمد على الاسم الذي يدخله الزائر (كما يعتمد ملف الإنجازات الحالي على الاسم). هذا مناسب لتجربة فعالية بسيطة لكنه ليس إثبات هوية قويًا؛ يمكن لشخص استخدام اسم شخص آخر. إذا أردت منع ذلك، يلزم تسجيل دخول لكل مشارك أو رمز مشارك فريد موثوق.

توليد صورة QR يتم عبر خدمة QR خارجية عند فتح نافذة الرمز، لذلك يحتاج اتصال إنترنت في لوحة الإدارة. رابط المسح نفسه يفتح موقع GitHub Pages ويعمل دون الحاجة إلى مكتبة مسح داخل الموقع.
